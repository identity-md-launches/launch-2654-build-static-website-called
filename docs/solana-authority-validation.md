## Reproduction and correction

Before editing source, served the existing production `dist/` under an IPFS-like subpath in Chromium **141.0.7390.37**, at **390 × 844**. Intercepted the supplied mint address and the two configured Solana endpoints. An object-valued mint authority, omitted mint authority, and boolean freeze authority each completed Token facts as “None” after **2 primary requests and 0 fallback requests**. All five checks were enabled and the Scam red flags prompt contained the unsupported “None.” The object case also completed with a malformed fallback configured. Recorded in [solana-authority-reproduction.json](solana-authority-reproduction.json).

**High, fixed — `src/scan-rpc.js:115`.** Each mint/freeze authority must now be explicitly `null`, or a base58 string that decodes to exactly 32 bytes. Only explicit `null` renders “None.” Missing, object, boolean, numeric, array, empty, invalid-character, wrong-byte-length and whitespace-padded values throw `ReadError`. Valid addresses retain the existing plain-text address and “Flag: set.” The existing whole-read retry in `src/scan-rpc.js:138` restarts on the distinct fallback; the existing error handler in `src/scan-view.js:228` displays “Could not read the chain right now” without facts or research controls if both reads fail.

The rebuilt production export passes **24 browser scenarios**: 6 malformed values × 2 authority fields × valid/malformed fallback. Each performs **2 primary and 2 fallback requests**, including a fresh mint and metadata read at the fallback. A deliberately different primary supply is discarded, the completed facts and prompts use the fallback authorities, and a second malformed reply leaves no completed facts, checks or prompts. The script additionally checks the pending state with a held fallback, keyboard submit/retry, valid-address flags, explicit nulls without fallback, and recovery after an error. [Focused results](solana-authority-checks.json) and [reproducible script](../scripts/validate-solana-authorities.mjs).

Unit regression tests in `tests/scan.test.mjs:233` cover 11 malformed values for each authority on both supported Token Programs, including strings that are base58 but decode to 31 or 33 bytes. Explicit null and valid authority combinations are also checked. All **78 unit tests** pass.

No other product source, styling, chain URLs, prompts, dependencies, build configuration or ignored paths changed. The existing site, lockfile and complete static export remain present. `dist/assets/app.js` was regenerated by the production build.
